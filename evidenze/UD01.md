# Evidenza — Preparazione dell'ambiente e metodo di lavoro

## Ambiente verificato

La postazione utilizza Windows con WSL 2 e Ubuntu 24.04.4 LTS. Il progetto è conservato nel filesystem Linux e viene aperto con Visual Studio Code tramite l'estensione WSL.

| Componente         | Versione o stato pubblicabile | Verifica eseguita                 |
| ------------------ | ----------------------------- | --------------------------------- |
| WSL                | 2.7.13.0                      | `wsl --version`                   |
| Ubuntu             | 24.04.4 LTS                   | `lsb_release -d`                  |
| Visual Studio Code | 1.134.0                       | `code --version`                  |
| Git in Ubuntu      | 2.43.0                        | `git --version`                   |
| Azure CLI          | 2.90.0                        | `az version`                      |
| Docker CLI         | Non rilevata                  | Verifica diagnostica dello script |

## Workflow completato

Il materiale del corso è stato utilizzato dal repository del corso e il lavoro è stato svolto nel repository personale `azure-devops-lab`, all'interno del filesystem Linux di WSL 2. Il repository è stato aperto con Visual Studio Code tramite l'estensione WSL.

Durante il lavoro, `git status` permette di verificare quali file sono modificati o non ancora tracciati. Con `git add` vengono selezionate le modifiche da includere nel commit, mentre `git commit` registra le modifiche nella cronologia locale del repository. Infine, `git push` pubblica i commit sul repository remoto GitHub.

L'inventario finale ha confermato la presenza di Ubuntu 24.04.4 LTS, Git 2.43.0, Visual Studio Code 1.134.0, Azure CLI 2.90.0 e Python 3.12.3. Docker CLI non è stata rilevata; l'installazione è rinviata alla UD dedicata a Docker.

### Problema incontrato o possibile

Azure CLI inizialmente non era installata nell'ambiente WSL. È stata installata tramite il repository ufficiale Microsoft e la verifica `az version` ha confermato la versione 2.90.0.

Il successivo `az login --use-device-code` ha completato l'autenticazione, ma non ha rilevato subscription associate all'account utilizzato. La verifica `az account show --output table` non è quindi risultata disponibile.

La questione relativa all'accesso alla subscription Azure sarà verificata con il docente del corso.

### Prima verifica diagnostica

Il comando `pwd` ha restituito un percorso interno al filesystem Linux di WSL, confermando che il repository non si trova sotto `/mnt/c`.
